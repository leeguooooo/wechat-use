微信工具设置

从 v1.18.6 起，首次安装和后续恢复使用同一个设置窗口。窗口只显示当前还缺的步骤，已经有效的状态会被复用。

安装一次，后续从窗口继续

curl -fsSL https://raw.githubusercontent.com/leeguooooo/wechat-use/main/install.sh | bash

安装器会准备完整组件。需要你操作时会显示“微信工具设置”；已有安装就绪时直接完成。之后可在“应用程序”中打开“微信工具设置”，无需输入诊断或修复命令。

新用户与老用户

情况窗口如何处理
首次使用在窗口粘贴激活码；按提示完成工具专用微信登录和 macOS 必要授权。数据准备、后台连接和结果检查自动进行。
已有有效登录和授权复用现有状态，不要求重新激活、重新登录或重复授权。已验证可用时，不重复发送测试消息。
缺少系统权限从实际后台程序请求权限，打开系统授权页。缺少条目时，直接把窗口提供的真实文件图标拖入，再打开开关。
旧开关已开，实际仍不可用选择“已开启但不生效”，先自动刷新后台检查。仍失败时，只按窗口提示重新添加对应的旧工具条目，其他应用权限保持原样。
组件不兼容优先使用电脑中已安装的兼容组件，只调整微信工具的运行配置。没有兼容组件时，窗口引导系统安装，完成后继续检查。
账号发生变化先确认是否使用当前账号，再保存旧配置并准备新账号，不强制退出当前登录。
中途关闭保留已完成的安装、登录和初始化结果。再次打开窗口时从当前状态继续。

什么时候算完成

以实际后台服务、权限、账号和发送核验结果为准。系统列表里显示开关已开启，或某个命令执行成功，都不单独算作完成。

需要发送验证时，工具会向文件传输助手发送一条测试消息。微信正在前台使用时，窗口会等待你点击“验证并完成”，避免干扰输入。未确认送达的测试不会自动重发。

微信登录、macOS 身份确认和系统许可必须遵守系统要求。设置窗口负责把这些操作定位清楚，并在完成后自动继续；不会静默绕过授权，也不会全局清空其他应用权限。
