设置遇到问题，不用自己查环境

以下是 v1.18.7 候选版的处理方式，尚未正式发布。当前 v1.18.6 不包含这些改进，请勿反复重装以寻找新入口。

v1.18.7 的所有设置页面都提供“复制诊断信息”，包括正在等待的页面。系统和工具版本由窗口采集，无需运行诊断命令。

按窗口提示继续

问题代码处理入口
WXS-DEVTOOLS / WXS-I-DEVTOOLS点击“授权并继续”，由本人在 macOS 弹窗中确认开启系统级开发工具授权，随后工具自动继续。
WXS-PERMISSIONS按窗口提示开启对应工具权限；系统列表缺项时拖入窗口提供的工具文件。
WXS-I-ACCESS / WXS-I-KEYS / WXS-I-UNKNOWN保持专用微信登录，复制诊断信息反馈，不反复重装或清空授权。
WXS-SERVICE工具会先尝试恢复后台；仍未恢复时，复制诊断信息反馈。
WXS-UI-…设置服务尚未启动或连接中断。窗口仍能复制基本环境诊断，不需要先运行命令。

如何反馈

截图保留完整的问题代码，或点击“复制诊断信息”后粘贴给协助处理的人。诊断包括系统版本、工具及专用微信版本、后台和权限状态，以及可识别的失败类别。初始化错误记录也会保存在本机。

诊断不包含聊天内容、激活码或数据库密钥，不会自动上传。即使设置服务没能启动，窗口本身仍能提供系统版本和连接状态。

仍在使用 v1.18.6

请先保持专用微信登录和现有数据。待 v1.18.7 正式发布后，原错误页的“修复安装”按钮可用于升级，随后按具体提示继续，无需另输命令。
