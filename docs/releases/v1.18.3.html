wechat-use v1.18.3

后台收发、初始化缓存复用与异常恢复更新 · 2026-09-07

这版改了什么

场景更新
发送文本和图片自动准备工具专用微信中的聊天，核对收件人后后台发送。无需手动点开文件传输助手，也无需手动确认图片预览。
已登录后再次初始化复用有效读取缓存，避免重复初始化影响正在使用的微信。切换账号后刷新工具的读取服务。
发送中断或超时增加发送前账号检查和发送结束后的进程恢复。不确定送达时提示先核对记录，不自动重发。
安装与权限普通安装、初始化和权限错误不再自动打开系统设置或 Finder。需要交互授权时给出明确操作命令。
HTTP 接入原生与 Hermes 图片请求支持桥接主机上的本地图片路径。图文同时提交会明确报错，请分开发送。
搜索修正部分旧索引缺少会话信息时，按会话搜索漏掉记录的问题。

安装与升级

curl -fsSL https://raw.githubusercontent.com/leeguooooo/wechat-use/main/install.sh | bash

适用于 Apple Silicon Mac 和工具专用微信 4.1.9。首次使用请登录专用微信并运行：

wechat-use init
wechat-use doctor

首次安装所需的微信登录与 macOS 权限仍需要本人完成。请保留现有登录和数据，不要为了升级删除账号目录。

目前的限制

新账号发图片仍需至少 3 条文件传输助手记录完成发送者校准；不足时会报 self_sender_uncalibrated，图片尚未提交。首次新聊天的 CLI 监听仍在排查。普通文件、视频和卡片的原生发送，以及部分 Wechaty 多消费者续传场景尚未完成。

发送耗时与电脑、微信状态有关。本轮本机文本和图片测试约 13–20 秒；这不是对所有设备的速度保证。遇到未确认送达，请先核对目标聊天，避免重复发送。
