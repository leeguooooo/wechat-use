微信工具首次授权

适用于 v1.18.5 及以上版本。登录「微信 4.1.9（工具专用）」后，在终端运行 wechat-use init。

跟随自动引导授权

缺少辅助功能权限时，交互式初始化会打开系统设置，并在 Finder 中选中 wechatd 和 wechat-bridge。若列表中没有这两个程序，将选中的文件拖入「隐私与安全性 → 辅助功能」，然后打开它们的开关。系统要求身份验证时，由本人完成。

工具会自动复验，最多等待 120 秒。授权通过后继续初始化；已有微信登录和数据库密钥保留，无需手动选择聊天。已授权的电脑不会打开设置或 Finder。

若当前由智能体或脚本执行，默认保持后台。需要引导时运行：
wechat-use init --fix-tcc
Finder 无法选中文件时，终端会显示完整路径，可在辅助功能设置中点「+」，按 Cmd+Shift+G 粘贴路径添加。

初始化结果

结果处理
needs_permissions密钥初始化结果已保留，发送权限尚未授权。完成拖拽及开关授权即可；等待超时后可重跑初始化。
permission_check_unavailable未能核验后台服务。运行 wechat-use doctor --json 查看原因；不要清空系统授权或重新提取密钥。
send_permission_ready=true后台进程的辅助功能权限已确认。消息是否送达仍以发送结果为准。

init --json 默认不打开窗口；--skip-smoke 只跳过发送自测，仍会检查权限。

安装时自动完成后台授权

curl 安装器通过 launchd 启动安装好的工具申请权限，不从终端派生另一个 init 来代替后台服务申请授权。安装过程中无需额外输入修复命令；列表缺项时，将 Finder 已选中的程序拖入辅助功能列表并打开开关。

授权完成后，工具自动刷新自己的后台服务，再核验 wechat-bridge 和 wechatd。微信进程、登录及密钥保留。此流程随安装脚本更新，命令行程序版本仍为 1.18.5。

旧条目已经开启

正常升级无需删除或重建全部授权。已有授权有效时直接继续；系统仍拒绝当前程序时才进入授权引导。同名条目不能证明当前后台进程已经获得授权，请以实际进程的检查结果为准。不要全局重置其他应用权限。

服务注册本身失败时会显示原始错误，不将其误报为权限问题。当前启动日志保存在 ~/Library/Logs/wechat-use/bridge.err，旧日志保留为 bridge.err.previous。
